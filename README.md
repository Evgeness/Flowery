# 🌿 Flowery

Веб-приложение для помощи в уходе за домашними растениями.

## 📖 О проекте

**Flowery** помогает пользователю отслеживать свои растения, получать информацию об уходе и своевременно узнавать о необходимости полива. Уведомления и подтверждение полива происходят через интеграцию с Telegram-ботом.

## ✨ Возможности

- 🔐 **Безопасная авторизация**: Регистрация и вход с использованием JWT (Access + Refresh токены).
- 🏠 **Главный экран (Dashboard)**: Список отслеживаемых растений с расчетом даты следующего полива.
- 📚 **Каталог растений**: Выбор растений из общего справочника (с загрузкой фотографий).
- 💧 **Трекинг полива**: Отметка о поливе в один клик с автоматическим пересчетом следующей даты.
- 🖼️ **Загрузка изображений**: Хранение фотографий растений в объектном хранилище MinIO.
- 🤖 **Telegram-бот**: Уведомления о поливе и подтверждение действий прямо в мессенджере.

## 💻 Frontend

### Стек технологий
- **React 18** — основа для построения пользовательского интерфейса.
- **TypeScript** — статическая типизация для надежности кода.
- **Vite** — сверхбыстрый сборщик.
- **React Router DOM** — клиентская маршрутизация (SPA).
- **Material-UI (MUI) v5+** — библиотека UI-компонентов.
- **Axios** — HTTP-клиент для взаимодействия с API (с настроенными интерсепторами).

### Архитектура (Упрощенный Feature-Sliced Design)
Проект использует модульную структуру для удобства масштабирования:
- **`app/`**: Инициализация приложения (роутинг, тема MUI, глобальные провайдеры).
- **`pages/`**: Экраны приложения (Dashboard, PlantSelection, Auth и др.).
- **`features/`**: Пользовательские сценарии и логика (например, валидация форм).
- **`entities/`**: Бизнес-сущности (типы данных `User`, `Plant`).
- **`shared/`**: Переиспользуемый код: UI-компоненты (`Layout`, кнопки), API-клиент (`axios.ts`), утилиты.

### Дизайн и UX
- **Эко-стиль**: Нежно-зеленая палитра, кастомный SVG-паттерн с листьями на фоне, рукописный шрифт *Caveat* для логотипа.
- **Интерактивность**: 
  - Плавные анимации появления карточек (CSS `@keyframes` и `Fade`).
  - Hover-эффекты на кнопках и карточках.
  - Состояния загрузки (`CircularProgress`, `Skeleton`) и обработка ошибок (`Alert`).
- **Валидация форм**: Проверка ввода на клиенте (email, длина пароля, совпадение паролей) с выводом понятных ошибок.
- **Адаптивность**: Интерфейс корректно отображается на мобильных устройствах, планшетах и ПК (сетки карточек автоматически перестраиваются).

### Работа с API
Настроен перехватчик (interceptor) Axios:
- Автоматически подставляет `access_token` в заголовки.
- При получении ошибки `401 Unauthorized` автоматически запрашивает новый `access_token` по `refresh_token` и повторяет исходный запрос. Если refresh-токен невалиден — разлогинивает пользователя.

## ⚙️ Backend

### Стек технологий
- **Python 3.12+** — язык программирования серверной части.
- **FastAPI** — современный асинхронный веб-фреймворк.
- **PostgreSQL** — надежная реляционная база данных.
- **SQLAlchemy 2.0 (Async)** — асинхронная ORM.
- **Alembic** — инструмент для миграций базы данных.
- **Pydantic v2** — валидация данных.
- **MinIO** — S3-совместимое хранилище для загрузки и раздачи изображений растений.
- **Passlib / JWT** — безопасность (хеширование паролей bcrypt, генерация токенов).

### Архитектура и безопасность
- **Слоистая структура (Clean Architecture)**: Код разделен на маршруты (`api/routes`), бизнес-логику (`crud`), модели БД (`models`) и схемы валидации (`schemas`).
- **Асинхронность**: Все операции с БД и внешними сервисами (MinIO) выполняются через `async/await`.
- **Ролевая модель**: Разделение прав доступа (`USER` и `ADMIN`). Только администраторы могут редактировать каталог растений.
- **UUID и Telegram**: Первичный ключ пользователя — `UUID`, что безопасно и удобно для привязки аккаунта к Telegram-боту.

### База данных
- **Users**: Данные пользователя, роль, UUID, `telegram_id`.
- **Plants**: Общий каталог (название, описание, интервал полива, `image_url`).
- **UserPlants**: Связь пользователя с растением (кастомное имя, `last_watered_at`, `next_watering_at`).

### API (Основные маршруты)
- **`/api/auth`** — Регистрация, вход, обновление токенов (`/refresh`), получение профиля (`/me`), выход.
- **`/api/plants`** — Получение каталога (публично) и CRUD-операции для админов.
- **`/api/plants/{id}/image`** — Загрузка изображения в MinIO (только Админ).
- **`/api/my-plants`** — Добавление растения себе, просмотр, удаление.
- **`/api/my-plants/{id}/water`** — Отметка полива (автоматически пересчитывает дату).

## 🐳 Docker (Развертывание)

Проект полностью контейнеризирован. В `docker-compose.yml` настроены 4 сервиса:
1. **db** — PostgreSQL 15.
2. **backend** — FastAPI (Python).
3. **frontend** — React + Nginx (раздача статики).
4. **minio** — Хранилище для картинок.
