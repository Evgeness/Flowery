# Flowery

Веб-приложение для помощи в уходе за растениями.

## О проекте

Flowery помогает пользователю отслеживать свои растения, получать информацию об уходе, Уведомления о поливе приходят через Telegram-бота.

## Возможности

- Регистрация и авторизация пользователей
- Главный экран со списком отслеживаемых растений
- Добавление растения из базы
- Просмотр информации о растении и советов по уходу
- Уведомления о поливе через Telegram
- Подтверждение полива в Telegram-боте

## Frontend

Экраны приложения:

- Авторизация
- Регистрация
- Главный экран
- Выбор растения
- Экран растения

## Backend

- База данных пользователей
- База данных растений
- База данных растений пользователя
- Отслеживание состояния растений
- API

## Telegram-бот

- Уведомления о поливе
- Подтверждение полива по кнопке
- Отслеживание полива растений
- Регистрация через ID и пароль
